# AI 分析结果数据结构规范

本文档定义了 AI 返回的分析结果数据结构。它是 AI 模块与下游消费者之间通信的唯一事实来源。

## 设计哲学

AI 分析结果分为七个维度，全面刻画用户画像：

1. **summary**：自然语言总结，一段话概括用户特征。
2. **professional**：专业画像 — 技术栈、职业方向、成长轨迹。
3. **personal**：个人画像 — 兴趣爱好、人生阶段、价值观。
4. **psychological**：心理画像 — 基于 OCEAN 大五人格模型量化评分。
5. **behavioral**：行为画像 — 社区角色、互动风格、活跃模式。
6. **social**：社交画像 — 内容吸引力、讨论深度。
7. **risk**：风险评估 — 账号异常检测（水军/买卖）。

> [!IMPORTANT]
> **校验策略**：采用宽松模式，缺失字段用默认值填充并生成警告，不直接报错。校验器返回 `{ data, warnings }`。

---

## 1. summary - 用户画像总结

| 字段      | 类型     | 说明                           | 默认值                     |
| :-------- | :------- | :----------------------------- | :------------------------- |
| `summary` | `string` | 一段自然语言的用户画像概括描述 | `"数据缺失，无法生成摘要"` |

---

## 2. professional - 专业画像

基于用户帖子的节点分布、内容深度和时间跨度推断。

| 字段              | 类型       | 说明             | 默认值   |
| :---------------- | :--------- | :--------------- | :------- |
| `tech_stack`      | `string[]` | 推断的技术栈列表 | `[]`     |
| `career_path`     | `string`   | 职业方向推断     | `"未知"` |
| `level`           | `string`   | 技术水平推断     | `"未知"` |
| `focus_coherence` | `string`   | 技术关注一致性   | `"未知"` |
| `evolution`       | `object`   | 技术演变轨迹     | 见下方   |

### evolution 子结构

| 字段       | 类型                       | 说明                 | 默认值   |
| :--------- | :------------------------- | :------------------- | :------- |
| `summary`  | `string`                   | 总体趋势描述         | `"未知"` |
| `timeline` | `EvolutionTimelineEntry[]` | 按时间排列的演变记录 | `[]`     |

#### EvolutionTimelineEntry

| 字段     | 类型     | 说明                   |
| :------- | :------- | :--------------------- |
| `period` | `string` | 时间段，如 "2019-2020" |
| `focus`  | `string` | 该时段的主要关注点     |

---

## 3. personal - 个人生活画像

基于非技术类帖子和回复内容推断。

| 字段         | 类型       | 说明         | 默认值   |
| :----------- | :--------- | :----------- | :------- |
| `hobbies`    | `string[]` | 兴趣爱好     | `[]`     |
| `life_stage` | `string`   | 人生阶段推断 | `"未知"` |
| `values`     | `string[]` | 价值观关键词 | `[]`     |

---

## 4. psychological - 心理画像

基于大五人格模型 (OCEAN) 进行推断。

> [!IMPORTANT]
> **分数范围**：所有分数必须在 0-100 之间。超出范围的值会被钳位（clamp），并生成警告。

### scores

| 字段                | 类型     | 说明                | 范围  | 默认值 |
| :------------------ | :------- | :------------------ | :---- | :----- |
| `openness`          | `number` | 开放性 — 兴趣广度   | 0-100 | `50`   |
| `conscientiousness` | `number` | 尽责性 — 条理严谨度 | 0-100 | `50`   |
| `extraversion`      | `number` | 外向性 — 社交活跃度 | 0-100 | `50`   |
| `agreeableness`     | `number` | 宜人性 — 友善温和度 | 0-100 | `50`   |
| `neuroticism`       | `number` | 神经质 — 情绪波动度 | 0-100 | `50`   |

### keywords

| 字段       | 类型       | 说明           | 默认值 |
| :--------- | :--------- | :------------- | :----- |
| `keywords` | `string[]` | 性格关键词标签 | `[]`   |

---

## 5. behavioral - 行为画像

基于用户的发帖/回复模式推断。

| 字段                | 类型     | 说明       | 默认值   |
| :------------------ | :------- | :--------- | :------- |
| `role`              | `string` | 社区角色   | `"未知"` |
| `interaction_style` | `string` | 互动风格   | `"未知"` |
| `active_pattern`    | `string` | 活跃模式   | `"未知"` |
| `heat_sensitivity`  | `string` | 热点敏感度 | `"未知"` |

---

## 6. social - 社交画像

基于用户内容的吸引力和讨论参与深度推断。

| 字段               | 类型     | 说明           | 默认值   |
| :----------------- | :------- | :------------- | :------- |
| `content_appeal`   | `string` | 内容吸引力特征 | `"未知"` |
| `discussion_depth` | `string` | 讨论参与深度   | `"未知"` |

---

## 7. risk - 风险评估

基于活动周期的中断模式和前后内容风格差异推断。

| 字段     | 类型                                    | 说明     | 默认值   |
| :------- | :-------------------------------------- | :------- | :------- |
| `level`  | `'safe' \| 'suspicious' \| 'high_risk'` | 风险等级 | `"safe"` |
| `reason` | `string`                                | 判断理由 | `"未知"` |

---

## 校验与默认值策略

校验器 (`parser/validator.ts`) 的行为：

| 场景             | 处理方式                   |
| :--------------- | :------------------------- |
| 字段缺失         | 填充默认值，添加警告       |
| 类型不匹配       | 使用默认值，添加警告       |
| 分数超出 0-100   | 钳位到范围内，添加警告     |
| 风险等级无效     | 降级为 `"safe"`，添加警告  |
| 响应不是有效对象 | 返回完整默认结构，添加警告 |
